# 라쿠카라차 3D

한 대의 PC·태블릿에서 **2~4명이 번갈아 플레이**하는 three.js 보드게임 웹앱입니다.
서버 없이 동작하는 정적 사이트이며, **텍스처와 효과음은 모두 코드로 생성**합니다(외부 이미지·오디오 0개).

원작: Ravensburger «La Cucaracha» (Peter-Paul Joopen) · 한국어판 코리아보드게임즈

## 실행

```bash
npm install
npm run dev      # http://localhost:5185 (같은 와이파이의 태블릿에서도 PC IP:5185 로 접속 가능)
npm test         # 규칙·물리 단위 테스트
npm run build    # dist/ 생성
```

## 배포

`main` 브랜치에 push 하면 GitHub Actions 가 테스트 → 빌드 → GitHub Pages 배포까지 자동으로 합니다.
(최초 1회: 저장소 Settings → Pages → Source 를 **GitHub Actions** 로 선택)

## 규칙 요약

- 라쿠카라차(바퀴벌레)는 **쉬지 않고 판 위를 돌아다닙니다**. 그 사이에 차례가 시계방향으로 돌아갑니다.
- **주사위를 굴려** 나온 그림에 해당하는 식사 도구 중 **하나를 90° 돌립니다**. 물음표면 종류 무관 아무거나 하나.
  주사위 6면 = 나이프 1 · 포크 1 · 숟가락 1 · **물음표 3**
- 식사 도구는 **포크 8 · 나이프 8 · 숟가락 8**, 모두 24개. 핀을 중심으로 **가로/세로** 두 방향만 가집니다.
- 판 네 귀퉁이의 **함정** 중 하나씩 고르고, 아무도 고르지 않은 함정은 **차단문**으로 막습니다.
  2명이 할 때는 **서로 마주보는 함정**을 골라야 합니다.
- 라쿠카라차가 함정에 빠지면 **그 함정 주인이 토큰 1개**. 4가지 배치 중 하나로 되돌리고 **토큰을 받은 사람부터** 새 라운드.
- **먼저 토큰 5개**를 모으면 승리. (룰북 변형: 먼저 5개를 모으면 **패배** — 설정에서 선택)

## 게임판 격자 (실물을 그대로 옮긴 부분)

실물 게임판은 **7×7 격자점 중 `(col + row)`가 홀수인 24자리**에만 고정핀이 박혀 있습니다(체커보드).
룰북 구성물의 고정핀 24개 · 식사 도구 24개와 정확히 일치하고, 사진에서 줄마다 세어지는 핀 개수(3‑4‑3‑4‑3‑4‑3)와도 맞습니다.

각 도구는 **길이 2칸짜리 막대이고 핀이 정중앙**에 있어서 가로(H)/세로(V) 두 상태만 가집니다
(룰북: *"세로 또는 가로로만 돌릴 수 있으며, 비스듬하게 둘 수는 없습니다"*).
그래서 **탭 한 번 = 90° 회전**이 원작 규칙과 정확히 대응됩니다.
체커보드 배치 덕분에 어떤 조합에서도 막대끼리 겹치지 않습니다.

플레이 영역은 격자 좌표 `x, y ∈ [-4, 4]`의 8×8 유닛이고, 가장자리 도구의 막대가 정확히 바깥 벽에 닿습니다.

## 조작

- **주사위 굴리기** 버튼(또는 <kbd>Space</kbd>) → **빛나는 식사 도구**를 눌러 90° 회전 → 다음 사람 차례
- 제한 시간(3·5·8초·무제한) 안에 돌리지 못하면 그냥 넘어갑니다
- 드래그로 시점 회전, 휠/두 손가락으로 확대·축소 · <kbd>Esc</kbd> 메뉴
- 태블릿은 가로·세로 모두 지원하며, 화면 비율에 맞춰 카메라가 자동으로 판 전체를 잡습니다

## 구조

| 경로 | 역할 |
| --- | --- |
| `src/game/board.js` | 24핀 격자, 벽 선분, 함정 입구·차단문 (순수 로직) |
| `src/game/layouts.js` | 룰북의 4가지 초기 배치 |
| `src/game/dice.js` | 주사위 6면 |
| `src/game/roach.js` | 라쿠카라차 물리 — 고정 타임스텝, 벽 충돌·미끄러짐, 끼임 해제 |
| `src/game/rules.js` | 차례·토큰·승패 판정 (순수 로직) |
| `src/game/state.js` | 자동 저장·이어하기 |
| `src/render/*` | three.js 씬, 절차적 테라조·원목 텍스처, 식사 도구·바퀴벌레·주사위, 연출 |
| `src/ui/*` | 시작 화면, HUD, 스타일 |
| `src/audio/sfx.js` | WebAudio 합성 효과음 |
| `tests/*.test.js` | 격자·규칙·물리 단위 테스트 |
